# v0.2 验证记录

日期：2026-10-12。环境：Windows，Tauri 2 / Rust 1.99 / WebView2。

## 完成的验证

- 前端构建：`pnpm build` 通过。
- TypeScript：`pnpm test`，8 项通过；覆盖配置兼容与敏感字段剔除、OpenSSH 通配符/否定匹配/首个值优先/引号/等号、代理及 Match 排除、重复连接合并。
- Rust：`cargo test --manifest-path src-tauri/Cargo.toml --lib`，7 项通过。
- 真实本机 SSH / SFTP：密码及 ED25519 私钥认证、指纹保存与变化拒绝、中文终端数据及约 200 KB 文件往返、同名拒绝覆盖。
- 传输：真实协议验证进度从 0 到完整字节数且不回退；中途取消上传清理新文件，中途取消下载保留已有文件且删除临时文件；写入失败清理新文件，服务器拒绝删除时返回具体远程路径。
- 连接关闭：只取消本连接传输，清理结束前保持连接，不允许关闭过程中启动新传输。
- 本地 PTY：真实 PowerShell 中文输出与取消关闭通过。
- Playwright 界面验证：OpenSSH 预览及选择导入/持久化、代理主机不可选择、实际分屏尺寸随拖拽/键盘改变、复位、尺寸通知；传输进度/取消入口在切换标签和隐藏文件面板后仍可用。
- 上述界面测试用模拟 IPC 验证前端交互，传输和 SSH 实际行为由 Rust 本机测试服务器验证；不是远程生产服务器测试。
- Windows 独立程序：`custom-protocol` Release 构建通过，启动后显示 v0.2 工作台及已有 v0.1 会话，无开发服务器依赖；系统标题栏深色属性为 1，运行中图标源为 256×256。
