# ChwellTerm

Windows / macOS 优先的 SSH 终端工作台，采用 Tauri 2、React、Rust 和 xterm.js。当前版本为 v0.9.2，正式命名为 **ChwellTerm**（原项目名 Terminal Workbench）。v0.1 已通过用户验收，归档在 `output/releases/v0.1/`。后续阶段及验收项见 [ROADMAP.md](ROADMAP.md)。

应用标题、设置页和新构建产物统一使用 ChwellTerm。为兼容已有会话、主机指纹、工作空间和已保存密码，沿用 `dev.terminalworkbench.app` 应用标识、`terminal-workbench` 系统凭据服务名及浏览器 `terminal-workbench-v1` 存储键；Rust 包和库名称也保留内部标识。历史版本文件名按原记录保留。

## 已实现

- 真实本地终端：Windows PowerShell、macOS / Linux 系统 shell。
- SSH 密码、私钥、本机 SSH Agent 及 keyboard-interactive / OTP 认证，加密私钥口令、30 秒保活。
- 私钥本地校验：联网前检查路径、文件格式、公钥误选、加密口令，显示对应跳板 / 目标的中文错误；支持带引号路径与 UTF-8 BOM。断开的标签提供“编辑连接”，重连使用最新已保存会话配置。
- 多轮交互式认证：服务器密码 / OTP 提示、多个输入项、隐藏 / 显示内容、取消和超时；跳板机和目标独立认证。密码 / 私钥 / Agent 收到服务器 partial-success 且要求 keyboard-interactive 时继续第二因子。
- 单跳跳板机：独立认证、逐跳指纹确认，目标终端和 SFTP 都经加密转发。
- 连接诊断：TCP、握手、指纹、认证、转发、PTY、SFTP 阶段和失败原因，可复制本次诊断；连接中可取消。
- SHA256 主机指纹确认、已知主机保存、指纹变化提示。
- 多标签、上下 / 左右分屏、拖拽调整比例及键盘操作、终端查找、日志查看、多行粘贴预览。
- 四宫格同时显示最多 4 个独立终端；点击切换当前面板，面板下拉框选择标签，已显示标签互换位置。左右 / 上下比例可独立拖拽及键盘调整，保存 / 恢复面板顺序与比例；窄窗口纵向排列并支持滚动。
- 工作空间保存、命名、重命名、更新和删除；保存标签顺序（含重复会话）、当前 / 第二面板、分屏方向 / 比例与文件面板状态。设置可启用启动恢复；所有恢复标签需手动连接。
- 复制连接：为当前会话建立新独立终端，SSH 凭据重新输入。
- 会话新增、编辑、删除、环境分组、搜索、本地配置持久化及 JSON 导入导出。
- SFTP 目录浏览、批量上传 / 下载和传输队列：一次多选本地文件上传，远程文件勾选 / 全选后下载到同一目录；逐项显示字节进度、平均速度、状态和错误。运行中可追加、取消等待 / 当前 / 全部任务，失败后继续；上传和批量下载均拒绝覆盖同名文件。
- 下载暂停与续传：暂停后保留断点并让其他任务继续；同一标签重连后手动继续。校验实际 SSH 身份、远端完整 SHA256、本地已下载部分及目标文件，确认完整后才提交。等待中的上传 / 下载也可暂停。
- 上传暂停与续传：使用独立远端临时文件，暂停释放队列，同一标签重连后手动继续；核对本地完整 SHA256、远端已上传部分及完成后的完整内容，再使用拒绝覆盖的 SFTP rename 发布。取消清理失败时保留任务与路径，关闭标签等待清理，清理失败保留原标签。
- 远程文本编辑：双击普通文件或选择后点击“编辑”，读取 UTF-8 文本、修改、Ctrl S / Command S 保存；保留 BOM、LF / CRLF，检查远端版本，备份原内容并安全替换。关闭 / 重新读取时保护未保存草稿，断开后可复制草稿。
- OpenSSH config 文件读取 / 文本粘贴、主机预览勾选及合并导入；重复连接跳过，同名不同连接自动加后缀。
- 命令片段、深浅主题、字号和字体设置、多会话输入广播。
- Windows Credential Manager / macOS Keychain 密码存储，密码和私钥内容不写入会话配置。

## 启动

本机最新 Windows 开发版可直接双击 `output/windows/ChwellTerm-v0.9.2.exe`，不需要启动开发服务器。系统需安装 WebView2 Runtime。Windows 构建脚本会输出该独立程序，NSIS 安装包在 `src-tauri/target/release/bundle/nsis/`。

需要 Node.js 22+、pnpm、Rust stable；Windows 需要 Visual Studio C++ 构建工具，macOS 需要 Xcode Command Line Tools。

```sh
pnpm install
pnpm desktop
```

本机已安装项目专用 Rust 工具链，Windows 可以直接使用：

```powershell
.\scripts\dev.ps1
```

仅查看界面：`pnpm dev` 或 `./scripts/dev.ps1 -Browser`，打开 http://127.0.0.1:1420。浏览器模式不能连接真实 SSH 或本地 shell。

需要直接打开 HTML 或在网站卡片中预览时，先运行 `pnpm web:build`，打开 `output/web/ChwellTerm.html`。这是包含脚本、样式与图标的独立网页；项目根目录的 `index.html` 是开发入口，需通过 Vite 服务使用。普通静态站点可运行 `pnpm build` 并部署整个 `dist/` 目录（支持子目录）。

## 使用

1. 首次启动点击“本地终端”即可运行本机 shell。
2. 点击“新建 SSH 连接”，填写主机、端口、用户名及认证方式。
3. 首次连接时核对指纹；密码认证可以勾选保存到系统凭据存储。
4. 打开至少两个终端，再点击工具栏“切换分屏”，依次切换左右、上下和单终端。
5. 拖动两个终端之间的分隔条调整比例；双击恢复 50:50，聚焦后用箭头键调整，Home / End 调至 20% / 80%。
6. SSH 连接后在右侧填写远程路径。上传选择框支持多选；下载可用文件左侧复选框或“全选当前目录文件”。多选下载统一选择目录，单文件下载仍支持另存为。底部队列可折叠，逐项取消、全部取消或清除已结束任务；切换会话或隐藏文件面板仍可查看。
7. “导入 / 导出” → “导入 OpenSSH config”：选择文件或粘贴内容，预览并勾选主机后导入。
8. 会话编辑中勾选“通过跳板机连接”，分别设置目标和跳板机的地址、用户名及认证方式；连接时分别输入凭据，依次核对两台服务器的指纹。
9. Agent 认证前在系统中启动 SSH Agent 并用 `ssh-add` 加载密钥；Windows 使用 OpenSSH 的 `\\.\pipe\openssh-ssh-agent`，macOS / Linux 使用进程环境中的 `SSH_AUTH_SOCK`。工具不会代为启用系统服务或添加私钥。
10. 连接栏点击“连接诊断”查看本次连接过程；日志仅在内存保留，重新连接重置，关闭标签清除。
11. 命令片段只插入文本；按 Enter 执行。广播启用后每个字符都会发送到所有勾选会话。

堡垒机 / OTP 登录：编辑会话，将对应服务器认证方式设为“交互式认证 / OTP”。连接后核对指纹，再按服务器提示输入密码、验证码；无需预先填写或保存 OTP。若你直接登录堡垒机菜单，把堡垒机作为主机地址；只有需要 TCP 转发到目标时才勾选“通过跳板机连接”。若报“跳板机：读取私钥失败”，检查跳板机认证方式；账号 / 密码 + OTP 应设为交互式认证，直接登录堡垒机菜单时不设置额外跳板。

工作空间：从侧栏“工作空间”或顶部布局图标进入，填写名称并保存当前布局。打开已保存工作空间会添加待连接标签，已有连接保留；点击标签中的“连接”启动认证。设置中可开启“启动时恢复上次工作空间”，默认关闭。工具栏“复制连接”为当前会话建立独立连接，不复制认证回答。

多面板：至少打开两个标签后，点击顶部“四宫格布局”按钮，最多同时显示四个终端。点终端内容或“聚焦”切换当前面板，右侧文件面板、搜索、日志和常用命令跟随当前标签，面板位置保持。每个面板顶部下拉框可选择任意打开标签；已在另一面板显示时互换位置。选择隐藏标签会替换当前面板，其他连接保留；空面板可“复制当前连接”。四宫格中的两条分隔条分别控制左右 / 上下比例（20%–80%），支持拖拽、Home / End、对应箭头键与双击复位。再次点击四宫格按钮返回单终端；“切换分屏”继续使用原有双面板方式。窗口宽度不超过 700px 时按保存的面板顺序纵向排列，滚动浏览，暂时隐藏比例控制。

工作空间引用已保存会话，恢复时采用会话的最新设置；删除的会话跳过并提示。上限为 100 个命名工作空间、32 个打开标签。导出包含工作空间，导入合并会话和命名工作空间，保留本机设置和上次布局；已有 ID 不覆盖。工作空间不保存终端内容、远端进程、广播状态、密码或 OTP。旧版程序保存配置时会丢弃新增工作空间字段，请保留新版源码 / 配置备份。

远程编辑：在已连接 SSH 的右侧文件列表双击文件，或选中文件后点击“编辑”。编辑窗口显示对应会话、完整路径、编码、换行和字节数。保存时会检查远端内容及元数据是否变化，并在同目录生成 `.twb-<随机 ID>.bak` 原内容备份；保存结果显示备份路径。备份保留在服务器上，可通过文件列表下载或终端恢复，按需手动清理。远端冲突时保留草稿，不提供强制覆盖；先复制草稿，再确认重新读取。草稿只在当前编辑窗口的内存中保留，不写入配置、工作空间或日志，退出整个应用会丢失未保存草稿。

配置由 Tauri 保存到系统应用数据目录，文件名为 `config.json` 和 `known-hosts.json`。配置导出不会包含密码、密钥口令及私钥内容。

## 本版边界

- 交互认证支持最多 32 轮、每轮 16 个输入项；每轮用户回答限时 5 分钟，网络认证请求限时 30 秒。认证失败需重新连接；不自动把失败密码转为 OTP 试探，也不保存交互回答。组合 PreferredAuthentications 回退顺序仍不导入；多因素续接遵循服务器 partial-success 标记。
- 多跳跳板机、Agent 转发、退出后的任务恢复尚未实现。
- 远程编辑首批限 1 MiB 以内 UTF-8 普通文件；拒绝二进制内容、符号链接、目录及特殊权限文件。混合 LF / CRLF 文件修改后保存统一为选择的换行格式，窗口会提示。服务器必须支持 `posix-rename@openssh.com`，并允许原文件写入、同目录创建备份 / 临时文件及保留原权限、UID / GID；不满足时停止保存。保存采用同目录临时文件替换，写入失败清理临时文件，清理失败提示具体路径。冲突检查是保存前两次内容 / 元数据比较，SFTP 不提供跨客户端原子版本锁，仍无法消除最终检查到替换之间的外部写入竞争。替换保留普通权限和 UID / GID，不承诺扩展 ACL、xattr、硬链接关系或断电持久性；需要这些语义的文件请使用服务器上的专用工具。当前为单文件基础文本编辑器，没有语法高亮、编码转换或断开后的自动重试。
- OpenSSH 导入支持 Host/HostName/User/Port/IdentityFile、单跳 ProxyJump（别名或 user@host:port，含括号 IPv6）、PreferredAuthentications 的 password/publickey/publickey,password/keyboard-interactive 形式，IdentitiesOnly yes 需显式 IdentityFile。password 优先于 IdentityFile，publickey,password 使用公钥并提示不自动回退密码。首个值优先，支持通配符及否定匹配。不会调用 SSH 命令、执行 Match exec 或自动读取 Include。多跳/嵌套跳板、有效 ProxyCommand/Include、自定义 IdentityAgent、CertificateFile 或 PKCS11Provider 不按直连导入；含 Match 的整个文件不可导入，其他未支持项会列出提示。多个 IdentityFile 只取第一个，无私钥默认 Agent，可编辑为密码；IdentityAgent none 时无私钥使用密码。私钥需绝对路径或 ~/ 路径，支持 %h/%n/%r/%%，读取文件时也支持 %d。
- Agent 使用普通公钥进行本机签名，每次连接最多尝试前 6 个身份，认证总超时 60 秒；不支持 Agent 证书认证、Pageant、自定义 Agent 路径或向远程转发 Agent。macOS 从图形界面启动时须确保应用进程能获得正确的 SSH_AUTH_SOCK。
- 多面板首批为最多 4 个独立终端的四宫格，仍可打开 32 个标签；没有任意嵌套拆分、超过四个同时显示的面板或同一 SSH 连接追加 shell。复制连接建立新连接，SSH 重新认证。工作空间记录四宫格面板顺序与两个比例，启动恢复仍需手动连接。v0.6.0 可读取旧配置；v0.5.0 及更早版本无法识别包含 grid 的工作空间配置，使用新布局后应继续用新版，历史源码 / 程序归档保留。
- 下载先写临时文件。单文件另存为完整传输后替换用户确认的目标；批量下载使用原文件名，最终原子提交也拒绝覆盖同名本地文件，遇到冲突继续其他项。原已存在的单文件目标在续传与提交前检查 SHA256，如改变则停止覆盖；检查与最终替换之间仍有外部修改的竞争窗口。Windows 保留设备名、控制字符、路径分隔符及跨平台非法文件名会拒绝，请单独下载并指定本地文件名。取消会删除临时文件并保留原目标。上传先写入独立的 `.twb-upload-<随机 ID>.part`，暂停 / 中断 / 失败时保留临时文件供续传；完成校验后用 SFTP v3 标准 RENAME 发布（不使用覆盖目标的 POSIX rename）。取消时核对临时文件类型、长度与 SHA256 后删除；无法清理或文件已变时保留任务并提示路径，可重连重试或手动检查后再次取消。
- 队列按添加顺序一次执行一个文件，最多保留 200 项（含已结束任务）；支持运行中追加，超限时整批拒绝，可清除已结束后重选。任务绑定选择前的终端连接和目录，切换标签不改变目标；断开源终端取消尚未开始的等待任务，已开始或已暂停的上传 / 下载保留；原标签重连后需手动继续。关闭标签先等待取消和清理，上传清理失败时保留原标签，其他会话继续。队列只在内存保存，退出丢弃，不支持目录递归。进度表示已写入传输流的字节，全部写入后还需要服务器确认或本地同步，随后才显示完成。取消与关闭标签会等待清理结果，清理失败时保留处理入口；仅断开连接时，后端最多等待 22 秒让运行任务保存断点再关闭传输通道。
- 下载续传仅支持提供普通文件类型与文件大小的 SFTP 服务器。首次下载先读取整个源文件计算 SHA256；每次继续重新读取整个源文件校验，然后仅写入剩余部分；提交前再校验本地完整内容。因此会增加网络读取、磁盘校验和等待时间，校验中可暂停 / 取消。暂停 / 中断的临时文件占用目标目录磁盘空间，取消或关闭标签删除；不保存断点元数据，重启应用不能恢复，崩溃或强制终止可能留下临时文件。目标 / 跳板主机、端口、用户名、实际指纹与原连接一致才可继续；修改认证方式或重新输入密码 / OTP 可以，身份改变时需取消重下。运行和等待中的上传 / 下载均可暂停 / 继续。
- 上传续传要求远端临时文件可读写，并允许同目录创建、标准 RENAME 和删除。本地源文件每次继续都重新读取完整 SHA256；远端已上传部分必须逐字节匹配源文件前缀，才会采纳写入确认丢失时留下的尾部。发布前读回整个远端临时文件并重读本地源文件，因此有额外网络 / 磁盘开销；大文件校验期间会显示“校验文件中”。暂停等待当前写入块确认，通常最多一个 64 KiB 块（网络请求可能等待超时）。远端临时文件占服务器空间；退出整个应用不会保存断点，也不保证远端清理，退出前应取消上传，必要时按显示路径手动检查。最终路径检查 / 删除之间没有跨客户端原子版本锁；发布依赖服务器遵循 SFTP v3 的不覆盖 RENAME 语义，断电持久性和响应丢失后的最终结果不能保证。
- 重连建立新的远端 shell，不恢复原来的进程状态。需要持久工作会话时使用 tmux。
- 当前开发版没有自动更新、应用签名或安装包公证。

依赖锁定在 `pnpm-lock.yaml` 和 `src-tauri/Cargo.lock`。`.tools/` 是本机开发工具与临时验证资料，不参与应用发布。

图标源文件为 `public/app-icon.svg`。修改后运行 `pnpm icons:build`，会生成 Windows / macOS 图标，并将 ICO 最大尺寸排在首位，避免窗口与任务栏放大 16 像素图标。
